## Поиск и исправление багов, поиск UB (Miri), Valgrind

По результатам исполнения тестов и проверки инструментом Miri, Valgrind выявлены ошибки реализации функций:
- average_positive - расчет среднего проводится по всем элементам, а не по положительным; деление на длину исходного массива, а не надлину подмассива положительных значений;
- leak_buffer - утечка памяти
- sum_even - непредвиденное поведение при доступе за пределы массива;
- use_after_free - небезопасные вызовы не обособлены unsafe инстркцией;

### Оптимизация

#### slow_dedup

В функции поиска и устранения дубликатов источники повышенного потребления процессорного времени:
- реализован поиск уникальных значений прямым перебором, 
- создание лишней копии значения для добавления в результирующий контейнер;
- избыточная сортировка на каждой вставке в результирующий контейнер.

Функция поиска и исключения дубликатов уточнена:
- из массива исходных данных формируется HashSet и Vec фиксированной длины, для быстрого поиска и вставки значений;
- исключена избыточная сортировка на каждой вставке в результирующий контейнер.

#### slow_fib

В функции расчета числа Фибоначчи источником повышенного потребления процессорного времени является вычисление промежуточных результатов расчета несколько раз.

Функция расчета числа Фибоначчи уточнена:
- расчет осуществляется в линейном цикле.
